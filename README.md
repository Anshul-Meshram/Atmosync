# Atmosync

An AI-powered climate analysis and forecasting system focused on Canada.

## Project Architecture

Data → ML → RAG → LLM → API → Dashboard

## Modules 

### Data Module
Climate data collection, cleaning, preprocessing and feature engineering

### ML Module
Climate forecasting, anomaly detection, and event classification

### RAG Module
Climate document processing, embeddings, vector search and evidence retrieval

### LLM Module
Combines ML results and retrieved climate evidence to generate explanations

### API
Backend layer connecting the AI pipeline with the frontend

### Dashboard
Visualization and user-facing climate insights
